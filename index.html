YOU MADE IT OUT

The maze is a map of a problem.

Every turn you took has a little computer science hiding inside it.

01

The map: data structure

Think of each open tile as a dot on a map. A line joins two dots when you can walk between them. The dots and lines make a graph, a way to store places and paths.

02

Your plan: algorithm

An algorithm is a set of steps for solving a problem. In this game: start here, move along a path, collect candy, and find the door. Your moves are one route through the map.

03

How computers find a way

A computer can check connected tiles and remember where it has been. This is called search. Breadth-first search checks nearby tiles first, so it can find the shortest route when every step costs the same.
